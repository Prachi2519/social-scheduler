# Social Operations Scheduler Client

React + TypeScript frontend for the Social Operations Scheduler.

For full project setup, backend configuration, API routes, environment variables, and product documentation, see the root README:

```text
../README.md
```

## Scripts

```bash
npm run dev       # Start Vite development server
npm run build     # Type-check and build production assets
npm run lint      # Run ESLint
npm run preview   # Preview production build
```

## Optional Environment

Create `client/.env` if the API is not running on the default backend URL:

```env
VITE_API_BASE_URL=http://localhost:3000
```
